# Уточнение ширины и карты зрелости — дизайн

## Цель

Сделать основной столбец руководства заметно шире на больших экранах и вернуть аккуратный вид вариантам ответа в карте зрелости.

## Решение

- Увеличить читательскую ширину основного столбца с 72 до 82 знаков. Это относится ко всем главам руководства на широких экранах; мобильная ширина по-прежнему ограничена экраном и внутренними отступами.
- Для вариантов ответа карты зрелости использовать пять колонок только когда каждая карточка может быть не уже 12rem.
- При меньшей доступной ширине, начиная с планшетной, переключать варианты в три колонки. Два последних варианта переходят на следующую строку без сжатия текста.
- Сохранить существующую разметку, клавиатурную доступность, радиокнопки и состояние выбора. Меняются только правила CSS.

## Проверка

- На широком экране основной столбец шире прежнего, а пять вариантов карты располагаются на одной строке с целыми подписями.
- На промежуточной ширине карта становится сеткой 3 + 2, без наложений и горизонтальной прокрутки.
- На мобильном экране остаётся одна колонка вариантов.
- Существующие автоматические проверки страницы и логики карты проходят.
