## Правило использования

1. Сильный фактический тезис получает ссылку на первичный источник и дату проверки.
2. Процент эффективности сопровождается выборкой, методом и ограничениями; иначе он остаётся гипотезой.
3. Кейс поставщика подтверждает практику, но не универсальный эффект.
4. Для MCP, A2A, A2UI и Agent Skills перед финальным ревью повторно проверяется версия, при этом дата среза остаётся 2026-07-24.
5. Регуляторный раздел помогает найти норму и вопрос для юриста; он не выдаётся за юридическое заключение.
