# Карта полномочий человека и ИИ

## Когда нужен

До доступа к рабочей системе, при смене прав и при повышении уровня A0–A3.

## Кто отвечает

Владелец результата; владелец системы подтверждает фактические технические права.

## Обязательные поля

- Точное действие и его инициатор.
- Владелец результата, исполнитель, согласующий и проверяющий.
- Уровень A0–A3 и техническое право.
- Условие остановки, цена ошибки и резервный сценарий.

## Пустая форма

```
# Полномочия: [процесс]
Дата пересмотра:

| Действие | Инициатор | Владелец результата | Исполнитель | Уровень A0–A3 | Согласующий | Проверяющий | Техническое право | Цена ошибки | Остановка | Резерв |
|---|---|---|---|---|---|---|---|---|---|---|
| [действие] | | | | | | | | | | |
```

## Короткий пример

ИИ на A2 создаёт запрос на слияние только в ветке задачи. Инициатор — разработчик, владелец результата — владелец компонента, проверяющий — автор изменения. Слияние запрещено технически; после трёх сбоев проверок система переходит на A1, а запрос создаёт разработчик вручную.

## Критерий готовности

Организационная ответственность не смешана с техническим исполнением; уровень самостоятельности задан каждому действию, а не системе целиком.
