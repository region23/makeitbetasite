# AI-native книга v2 — новая многостраничная вёрстка (handoff)

## Что это
Редизайн `ai_native_book/`: уход от одностраничника к схеме «хаб + глава на страницу».
Чистая статика: HTML + инлайн-стили + один общий скрипт `assets/book-v3.js`. Без фреймворков и сборки.

## Состав папки
- `index.html` — хаб (обложка, маршруты А/Б, оглавление, восемь систем)
- `chapter-01.html` — Глава 1. Определение и границы
- `chapter-02.html` — Глава 2. Карта зрелости (интерактивная оценка, профиль, экспорт .md)
- `chapter-03.html` — Глава 3. Первый управляемый цикл
- `chapter-04.html` — Глава 4. Восемь систем операционной модели
- `chapter-05.html` — Глава 5. Контекст, память и навыки
- `chapter-06.html` — Глава 6. Жизненный цикл разработки программного обеспечения с ИИ
- `chapter-07.html` — Глава 7. Проверки качества и наблюдение
- `chapter-08.html` — Глава 8. Полномочия, безопасность и устойчивость
- `chapter-09.html` — Глава 9. Экономика (формула + структура расходов)
- `chapter-10.html` — Глава 10. План стартапа (таймлайн 90 дней)
- `chapter-11.html` — Глава 11. План зрелой компании (таймлайн 180 дней)
- `chapter-12.html` — Глава 12. Практический комплект (13 карточек шаблонов со скачиванием)
- `sources.html` — Приложение П1. Источники и стандарт доказательности
- `version.html` — Приложение П2. Версия и журнал изменений
- `full.html` — прежний одностраничник целиком (все якоря `#ch1…#ch12` работают)
- `assets/book-v3.js` — прогресс чтения, чек-листы, карта зрелости, копирование примеров, баннер «Продолжить»
- `assets/book-v2.css`, `assets/book-v2.js` — нужны только для `full.html`
- `templates/*.md` — 13 шаблонов (пути `./templates/…` не изменились)

## Как задеплоить
1. Скопировать содержимое папки в `ai_native_book/` (старый `index.html` предварительно сохранить — он уже лежит здесь как `full.html`).
2. Ничего не собирать: страницы самодостаточны.
3. Проверить, что `ai_native_book/v1/` осталась на месте (ссылки «Архив v1» ведут туда через full.html).

## Обратная совместимость ссылок
В `index.html` добавлен ранний скрипт-редирект для `#ch1…#ch12`, `#sources`, `#version`, `#changelog`, а также для ненумерованных legacy-якорей `#first-managed-loop` и `#context-memory-skills`.
Маршруты сохраняют старый смысл якорей: например, legacy `#ch3` ведёт в новую главу 4, а `#ch10` остаётся ссылкой на подраздел «Когда ИИ не нужен» в `full.html`.

## Дизайн-система (для доверстки глав 3–8 и 11)
- Шрифты: Literata (текст/заголовки) + JetBrains Mono (мета, номера, подписи) — Google Fonts, Cyrillic.
- Палитра: фон `#FBF7EE`, панели `#F4EEDD`/`#F7F1E2`/`#F1E7CF`, чернила `#171106`, приглушённый `#4A4030`/`#7A6B52`, акцент `#9C4A0E` (сильный `#6E3509`), линия `#C2782E`, опасность `#A83E1F`, зелёный `#5A6B35`, границы `rgba(23,17,6,0.14/0.22/0.28)`.
- Каркас страницы главы: шапка (← Оглавление · бренд · «Глава N из 12»), прогресс-бар 3px, опенер (номер моно 72–128px цветом `#C2782E`, метка части, h1 36–56px/800), контейнер 1280px, sticky-рельса «В этой главе» 200–240px, статья max-width 88ch, футер prev/next, разделители 2px `#171106`.
- Паттерны: таблицы с моно-капшеном на подложке `#F4EEDD` и min-width + overflow-x:auto; «Рабочая карточка главы» — грид-карта с моно-лейблами; чек-лист с `data-reading-check` (localStorage `ainb2-checks-<page>`); выделенные тезисы — левая рамка 3px акцентного цвета на тонированной подложке.
- Любая новая глава: скопировать `chapter-01.html` как каркас, заменить контент дословно из `full.html` (текст не менять), для табличных глав смотреть `chapter-10.html`.

## Ключи localStorage (общие для всех страниц)
- `ainb2-progress` — {ch1: 0..1, …} прогресс чтения
- `ainb2-last-read` — {ch1: timestamp, …} время последнего открытия главы
- `ainb2-scorecard` — баллы карты зрелости
- `ainb2-checks-<page>` — чек-листы
