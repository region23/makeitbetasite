# Реестр рисков

## Когда нужен

С первого производственного использования, при существенном изменении и после серьёзного инцидента.

## Кто отвечает

Владелец результата; владельцы мер подтверждают выполнение предотвращения, обнаружения и реакции.

## Обязательные поля

- Риск, причина, последствие и затронутые лица.
- Вероятность или неопределённость, тяжесть и остаточный риск.
- Предотвращение, обнаружение, реакция, владелец и дата пересмотра.
- Цена ошибки и резервный сценарий для существенного риска.

## Пустая форма

```
# Реестр рисков: [процесс]
Дата пересмотра:

| Риск | Причина | Последствие | Затронутые лица | Вероятность или неопределённость | Тяжесть | Цена ошибки | Предотвращение | Обнаружение | Реакция и резерв | Владелец | Остаточный риск | Пересмотр |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| [риск] | | | | | | | | | | | | |
```

## Короткий пример

Устаревшая цена может привести к неверному предложению клиенту. Предотвращение — не использовать источник старше суток; обнаружение — сверка цены перед отправкой; реакция — заблокировать отправку и вернуть заявку оператору. Владелец меры — коммерческий директор.

## Критерий готовности

Каждый существенный риск имеет владельца, предотвращение, сигнал обнаружения, выполнимую реакцию и явно принятую оценку остаточного риска.
