# Project: Make It Beta — Company Website

## What is this
Landing page / portfolio site for Make It Beta (makeitbeta.ru) — an AI-first pocket company.

## Requirements
- Modern, clean, professional landing page
- **LIGHT THEME ONLY. No dark mode. No dark theme. No dark backgrounds.**
- Use the /frontend-designer skill for all design work
- Single page with sections:
  1. Hero: "Make It Beta" — AI-first pocket company
  2. About: One founder + team of AI agents running the company
  3. Portfolio: 8 projects (see list below)
  4. Philosophy: AI-first approach, agents as team members
  5. Contact / Links
- Stack: pure HTML + CSS + minimal JS (no frameworks, keep it simple and deployable anywhere)
- Responsive (mobile-first)
- Russian language for content

## Design Guidelines
- Light, airy, modern
- Accent colors: can use tech-blue or vibrant gradients, but background MUST be light/white
- Clean typography

- Cards for portfolio items
