# Общая навигация сайта

Шапка и подвал хранятся в `header.html` и `footer.html`. После изменений выполните из корня репозитория:

```sh
python3 scripts/site_shell.py
python3 scripts/site_shell.py --check
```

Скрипт обновляет статические страницы и шаблон блога. Навигация присутствует в HTML и доступна без JavaScript. Генераторы статей и глав читают те же шаблоны. Локальное оглавление и переходы внутри руководств остаются на своих местах.

Полноэкранные диорамы не включены: это отдельные результаты эксперимента с собственным интерфейсом и управлением.
